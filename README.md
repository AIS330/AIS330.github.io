# AIS330.github.io

`https://ais330.github.io/` 첫 주소를 맡는 공개 저장소다. 앱이소 홈과 앱 소개는 [pages](https://github.com/AIS330/pages) 저장소(`/pages/`)에 있다.

- `index.html`: 첫 주소로 온 방문자를 앱이소 홈(`/pages/`)으로 보낸다.
- `google*.html`: Google Search Console 소유 확인 파일이다. 앱이소 글쓰기의 Google OAuth 브랜드 인증에 `ais330.github.io` 도메인 소유 확인이 필요해서 둔다. **지우면 소유 확인이 풀린다.**
- 이 저장소에 `pages` 폴더를 만들지 않는다. `/pages/` 경로는 pages 저장소의 사이트다.
